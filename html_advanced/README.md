# alu web development - HTML Advanced

![Smile School final design](smileschool_mockup.png)

This project is the first step of a series in which we implement a complete
webpage, from scratch, starting from a **designer file** provided on Figma.

For **this** first project, the focus is on the **HTML structure only**:
no CSS, no styling, no JavaScript — just pure, well-structured **semantic HTML**.

## Objectives

- Learn to read and understand a design file (Figma) before writing any code.
- Translate a visual design into a clean, semantic HTML structure.
- Practice the use of meaningful HTML elements: `header`, `main`, `section`,
  `article`, `aside`, `footer`, `figure`, `figcaption`, etc.
- Produce a page skeleton that will be styled with CSS in the upcoming projects.

## Getting started

The design file is available on Figma. Create an account, then:

1. Open the **Page in Figma**.
2. Click on **"Duplicate to your Drafts"** to get access to all design details.
3. Download the missing fonts if your computer does not have them:
   - [Source Sans Pro](https://fonts.google.com/specimen/Source+Sans+Pro)
   - [Spin Cycle OT](https://www.fontsgeek.com/)
   - (Some values in the design are floats — feel free to round them.)

## Requirements

- Pure HTML only — **no CSS**, **no styles**, **no inline styling**.
- Valid, semantic HTML5.
- The page must reflect the structure shown in the Figma design.
- No external CSS frameworks or libraries.
